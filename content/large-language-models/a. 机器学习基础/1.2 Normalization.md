## Normalization

### 归一化的动机与作用

- 训练深度网络的主要困难
  - 内部协变量偏移（Internal Covariate Shift）
  - 梯度爆炸与梯度消失
  - 学习动态不稳定
- 归一化如何缓解训练难点
  - 使激活分布更加稳定
  - 加速收敛
  - 提升模型泛化能力
  - 与正则化效果的关系（如 BatchNorm 带来的隐式正则化）

### 归一化的一般形式

- 输入 $x$ 的均值与方差计算
   $$\mu = \text{mean}(x), \quad \sigma^2 = \text{var}(x)$$
- 标准化
   $$\hat{x} = \frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}$$
- 仿射变换
   $$y = \gamma \hat{x} + \beta$$
- 关键差异在于 **均值/方差的统计维度（axes）**
  - Batch 方向
  - Feature 方向
  - Channel 方向
  - Group / Patch 方向

## Batch Normalization（BN）

### 定义与公式

- 批维度上计算均值/方差
- 训练与推理模式的区别：Running Mean / Running Var
- BN 的数学定义与推导

### BN 的优势

- 加速收敛
- 稳定梯度
- 隐式正则化（减少过拟合）

### BN 的问题

- 对 batch size 敏感
- 在 RNN、Transformer 等序列模型中表现差
- 多卡训练中的 SyncBN
- 小 batch 场景的 BN 退化问题

## Layer Normalization（LN）

### 定义与公式

- 在特征维度（feature dimension）上进行归一化
- 数学形式：对每个 token 独立归一化
- 不依赖 batch 维度

### 理论特点

- 更适用于 NLP、Transformer、RNN
- 对 batch size 不敏感

###  Transformer 中的使用

- Pre-LN vs Post-LN 架构
- 残差连接位置的讨论

## Group Normalization（GN）

### 动机

- 为 CNN 提供 BN 的替代方案
- 不依赖 batch size

### 公式与实现

- Channel 分组归一化：$C$ 通道 → $G$ 组
- 特殊情况：
  - $G=1$ → LN
  - $G=C$ → InstanceNorm

### 应用场景

- CV 中小 batch 训练
- Dense prediction（检测/分割）

## Instance Normalization（IN）

- 从图像风格迁移领域引入
- 每个样本、每个通道独立归一化
- 风格消除/内容保持的作用

## RMSNorm（Root Mean Square Layer Norm）

### 定义

- 去除均值（只使用方差）
   $$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \gamma$$

### 适用场景

- 大语言模型（LLaMA、Qwen2 等）
- 更稳定、更轻量

## Weight Normalization / Spectral Normalization

### WeightNorm

- 参数归一化，不是激活归一化
- 将权重拆分为
   $$w = g \frac{v}{|v|}$$
- 加速训练，但常被 LN 替代

### SpectralNorm

- 控制 Lipschitz 常数
- 在 GAN / 强化学习中常用
- 对抗训练的稳定性提升

## 各归一化方法对比

- 维度统计方式不同导致行为不同
- 适用任务场景对比
- Transformer → LN / RMSNorm
- CNN → BN / GN / IN
- 小 batch → GN / LN / RMSNorm
- 大模型 → RMSNorm / LN
