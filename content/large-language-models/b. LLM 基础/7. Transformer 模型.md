# 1. Seq2Seq 模型

## 1.1 Seq2Seq（Sequence-to-Sequence）

**概念：**

- 输入序列 → 输出序列的模型
- 典型任务：机器翻译、文本摘要、对话生成
- 核心特性：输入和输出长度不必相等

**公式表示：**

$$
  Y = f_\theta(X) \quad\text{其中 } X = (x_1,...,x_m), \quad Y=(y_1,...,y_n)
$$

**特点：**

- 强调“序列映射”关系
- 可以使用 RNN、LSTM、GRU 或 Transformer 实现
- 不一定是端到端的（可以有特征工程或分阶段处理）

## 2.2 End-to-End（端到端）

**概念：**

- 模型直接从原始输入到目标输出，不需要人工设计中间步骤
- 核心思想：所有处理通过一个模型学习完成

**特点：**

- 数据驱动，最小人工干预
- 例子：
  - 图片 → 描述（Image Captioning）
  - 语音 → 文本（ASR）
- End-to-End 是训练方式或设计理念，而非具体网络结构

## 2.3 Encoder-Decoder（编码器-解码器）

**概念：**

- 一种具体模型结构
- 分两步：
  1. **Encoder**：把输入序列编码成上下文向量（Context Vector 或一系列 hidden states）
  2. **Decoder**：根据上下文生成输出序列

**公式表示：**

**Encoder：**

$$
 H = \text{Encoder}(X) \quad\text{其中 } H=(h*1,...,h_m)
$$

**Decoder：**

$$
y_t = \text{Decoder}(y_{*{<t}}, H)
$$

**特点：**

- Encoder-Decoder 是 Seq2Seq 的典型实现方式
- 可以支持 Attention（增强性能，解决长序列瓶颈）

| 概念            | 类型      | 功能                 | 关系                                        |
| --------------- | --------- | -------------------- | ------------------------------------------- |
| Seq2Seq         | 任务/框架 | 序列到序列映射       | End-to-End 或非端到端都可实现               |
| End-to-End      | 设计理念  | 原始输入直接生成输出 | 可以使用 Seq2Seq/Encoder-Decoder 等模型     |
| Encoder-Decoder | 模型结构  | 编码输入 → 解码输出  | 是 Seq2Seq 的典型实现结构，可用于端到端训练 |
