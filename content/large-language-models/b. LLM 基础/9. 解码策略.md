# 主流解码策略的系统化技术解析

给定语言模型条件分布\
$p(x_t \mid x_{<t})$
解码策略的目标是在每一步 $t$ 为下一个 token $x_t$ 选择或采样一个值，从而形成最终序列。

# 1. Greedy Decoding（贪心解码）

## 1.1 定义

每一步直接选取概率最大的 token：

$$
x_t = \arg\max_{x} p(x \mid x_{<t})
$$

## 1.2 特性

| 属性       | 描述             |
| -------- | -------------- |
| **确定性**  | 是              |
| **多样性**  | 极低             |
| **质量**   | 易陷入局部最优，缺乏全局结构 |
| **重复风险** | 极高（产生循环、啰嗦）    |

## 1.3 优点与缺点

- **优点**：最快，无采样成本。
- **缺点**：输出单一、缺乏创造性，长文本质量差。

# 2. Beam Search（束搜索）

## 2.1 定义

维护大小为 $B$ 的候选集合（beam），在每一步扩展每个候选的所有可能 token，保留 top-$B$ 总概率的序列。

序列得分常用对数概率累积：

$$
\text{score}(x_{1:t}) = \sum_{i=1}^{t} \log p(x_i \mid x_{<i})
$$

可加入长度惩罚：

$$
\text{score}' = \frac{1}{(5+t)^\alpha} \text{score}
$$

## 2.2 特性

| 属性        | 描述                  |
| --------- | ------------------- |
| **确定性**   | 是（若无随机因素）           |
| **多样性**   | 低                   |
| **全球最优性** | 更强的结构性，但在 LLM 中实际不佳 |
| **重复控制**  | 稍好但依然较差             |

## 2.3 现代大模型中不推荐原因

- 增大 beam 会**降低**文本质量（与传统 NMT 不同）。
- 更倾向重复和模板化表达。

# 3. Top-k Sampling（截断采样）

## 3.1 定义

仅从概率前 $k$ 的 token 集合 $S_k$ 中采样：

$$
S_k = \text{Top-}k(p(x))
$$

采样分布：

$$
p_k(x) = \frac{p(x)}{\sum_{j \in S_k} p(j)}\quad x\in S_k
$$

## 3.2 特性

| 属性       | 描述                 |
| -------- | ------------------ |
| **确定性**  | 否                  |
| **多样性**  | 可控，$k$ 越大越随机       |
| **长尾控制** | 好（去除所有尾部 token 噪声） |
| **风险**   | 若 k 太小 → 倾向贪心、僵硬   |

# 4. Top-p Sampling（Nucleus Sampling，核采样）

## 4.1 定义

从最小集合 $S_p$ 中采样，使得：

$$
\sum_{x \in S_p} p(x) \ge p
$$

采样分布：

$$
p_p(x) = \frac{p(x)}{\sum_{j \in S_p} p(j)}
$$

## 4.2 特性

| 属性       | 描述                  |
| -------- | ------------------- |
| **确定性**  | 否                   |
| **适应性**  | 强（概率集中时减少候选数；分散时增加） |
| **多样性**  | 高且稳定                |
| **尾部噪声** | 有效过滤                |

## 4.3 优势

- 与 Top-k 的固定截断不同，top-p 根据上下文**动态**调整候选集合。
- 是 ChatGPT 早期默认策略。

# 5. Typical Decoding（典型解码）

Typical Decoding 由 *Maynez et al., 2020* 提出，是一种基于**信息论**的采样方法。

## 5.1 定义

选择 “信息量（surprise）最典型” 的 token 区域。

首先计算每个 token 的自信息：

$$
I(x) = -\log p(x)
$$

计算分布的信息熵：

$$
H = \sum_x p(x) \cdot (-\log p(x))
$$

典型性度量：

$$
\delta(x) = |I(x) - H|
$$

典型解码在所有 token 中选择 $\delta(x)$ 最小的 token 子集，再进行采样。

## 5.2 特性

| 属性       | 描述                        |
| -------- | ------------------------- |
| **目标**   | 选择 “典型” 而非 “最高概率” 的 token |
| **风格**   | 语言更自然、减少重复、保持连贯性          |
| **对创造性** | 比 top-p 更平衡               |

## 5.3 优点

- 克服 top-p 在某些分布中失效的问题（如 top-p 忽略信息量结构）。
- 更接近人类**自然语言熵**的生成行为。

# 6. Contrastive Decoding（对比解码）

由 Li et al. (2022) 提出，是一种结合 “大模型 + 小模型” 的**判别式解码策略**。

## 6.1 定义

给定一个强模型 $p_s$ 与一个弱模型 $p_w$，得分为：

$$
\text{score}(x) = \log p_s(x\mid x_{<t}) - \alpha \log p_w(x\mid x_{<t})
$$

选择最大得分的 token。

直觉：

- 强模型生成真实语义
- 弱模型捕捉语言噪声（共现偏差）
- 两者相减减少幻觉与重复

## 6.2 特性

| 属性      | 描述                 |
| ------- | ------------------ |
| **确定性** | 是                  |
| **质量**  | 高（减少重复、提升准确性）      |
| **延迟**  | 较高（需要双模型）          |
| **用途**  | 减少幻觉、提高 factuality |

# 7. 各解码策略技术对比

| 策略          | 随机性    | 多样性 | 信息利用  | 重复控制 | 质量稳定性 | 典型用途            |
| ----------- | ------ | --- | ----- | ---- | ----- | --------------- |
| Greedy      | 0      | 极低  | 局部    | 差    | 差     | 确定性任务           |
| Beam        | 0      | 低   | 全局（弱） | 中    | 中     | 结构化翻译（但不适合 LLM） |
| Top-k       | 中等     | 高   | 局部    | 中    | 中     | 创造性生成           |
| Top-p       | 中等 / 高 | 高   | 动态截断  | 良好   | 良好    | Chat 对话 / 通用生成  |
| Typical     | 中等     | 高   | 信息论最佳 | 良好   | 稳定    | 长文本生成           |
| Contrastive | 低      | 中   | 强判别   | 极佳   | 高     | 高真实度、减少幻觉       |
