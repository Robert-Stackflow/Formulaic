## 题面

给你一个整数数组 `nums` ，数组中的元素 互不相同 。返回该数组所有可能的子集（幂集）。

解集 不能 包含重复的子集。你可以按 任意顺序 返回解集。

示例 1：

    输入： nums = [1,2,3]
    输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]

示例 2：

    输入： nums = [0]
    输出：[[],[0]]

提示：

  * `1 <= nums.length <= 10`
  * `-10 <= nums[i] <= 10`
  * `nums` 中的所有元素 互不相同

## 分析

- 回溯的子集问题应用

	- 利用 startIndex 控制遍历哪些元素，防止重复
	- 回溯终止条件：startIndex 超过数组范围
	- 何时加入答案：每次 backtracking 都记录答案
	- 如何回溯：加入当前数组元素后，下一次 backtracking 的 startIndex+1，然后移除当前数组元素回溯

- 代码实现

	```cpp
	class Solution {
	public:
	    vector<vector<int>> res;
	    vector<int> path;
	    void backtracking(vector<int>& nums, int startIndex) {
	        if (startIndex > nums.size())
	            return;
	        res.push_back(path);
	        for (int i = startIndex; i < nums.size(); i++) {
	            path.push_back(nums[i]);
	            backtracking(nums, i + 1);
	            path.pop_back();
	        }
	    }
	    vector<vector<int>> subsets(vector<int>& nums) {
	        backtracking(nums, 0);
	        return res;
	    }
	};
	```


## 子集 II

- 如果数组中有重复元素呢？需要进行排序并进行同一层的去重操作

	```cpp
	class Solution {
	public:
	    vector<vector<int>> paths;
	    vector<int> path;
	    void backtracking(vector<int>& candidates, int start) {
	        paths.push_back(path);
	        for (int i = start; i < candidates.size(); i++) {
	            if (i > start && candidates[i] == candidates[i - 1])
	                continue;
	            int num = candidates[i];
	            path.push_back(num);
	            backtracking(candidates, i + 1);
	            path.pop_back();
	        }
	    }
	    vector<vector<int>> subsetsWithDup(vector<int>& candidates) {
	        sort(candidates.begin(), candidates.end());
	        backtracking(candidates, 0);
	        return paths;
	    }
	};
	```
